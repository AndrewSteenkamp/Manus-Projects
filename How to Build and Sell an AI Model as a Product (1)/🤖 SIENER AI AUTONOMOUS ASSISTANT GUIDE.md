### **DAY 5: TAX & COMPLIANCE**

#### **STEP 5.1: Complete SARS Registration (60 minutes)**
**Prerequisites:** CIPC certificate, bank account

1. **Log into:** SARS eFiling account
2. **Click:** "Register Taxpayer" → "Company"
3. **Enter details:**
   - Company registration number
   - Company name
   - Business address
   - Banking details
   - Main business activity: "Software development"
4. **Submit:** Application
5. **Save:** Tax reference number

#### **STEP 5.2: VAT Registration Decision (15 minutes)**
**Current rule:** Register for VAT if turnover > R1 million annually

**Decision matrix:**
- **If projecting < R1M first year:** Skip VAT registration initially
- **If projecting > R1M first year:** Register for VAT now

**To register for VAT:**
1. **In SARS eFiling:** "Register for Tax Type" → "VAT"
2. **Complete:** VAT registration form
3. **Submit:** Application

#### **STEP 5.3: UIF & PAYE Setup (30 minutes)**
**Only if hiring employees immediately:**

1. **In SARS eFiling:** "Register for Tax Type"
2. **Select:** PAYE and UIF
3. **Complete:** Employer registration
4. **Save:** Reference numbers

**⚠️ NOTE:** Skip if working alone initially

### **DAY 8-10: SYSTEM INTEGRATION**

#### **STEP 8.1: Custom Domain Setup (45 minutes)**
**Prerequisites:** Domain registered, hosting ready

1. **Access:** Domain DNS settings
2. **Add A record:**
   - Name: @ (root domain)
   - Value: [Your server IP]
   - TTL: 3600
3. **Add CNAME record:**
   - Name: www
   - Value: [Your root domain]
   - TTL: 3600
4. **Wait:** 24-48 hours for propagation
5. **Test:** Domain points to your Siener AI application

#### **STEP 8.2: SSL Certificate Setup (30 minutes)**
**Using Let's Encrypt (free):**

1. **SSH into:** Your server
2. **Run commands:**
   ```bash
   sudo apt update
   sudo apt install certbot python3-certbot-nginx
   sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
   ```
3. **Test:** https://yourdomain.com loads securely

#### **STEP 8.3: Payment Integration Testing (60 minutes)**
1. **Update:** Siener AI code with your Stripe keys
2. **Test:** Payment flows with Stripe test cards
3. **Verify:** Webhooks are working
4. **Test:** Subscription creation and cancellation
5. **Document:** Any issues for fixing

## 🆘 **EMERGENCY PROTOCOLS**

### **Technical Emergencies:**
1. **Website down:**
   - Check server status
   - Contact hosting provider
   - Activate backup systems
   - Communicate with customers

2. **Payment processing issues:**
   - Contact Stripe immediately
   - Activate PayFast backup
   - Notify affected customers
   - Process manual payments if needed

3. **Data security breach:**
   - Isolate affected systems
   - Contact security expert
   - Notify customers immediately
   - Report to authorities if required

### **Business Emergencies:**
1. **Cash flow problems:**
   - Review all expenses
