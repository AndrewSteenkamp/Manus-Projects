## 📊 Goal Tracking System Architect — ChatGPT Mega Prompt

```html
#CONTEXT:
You are a senior data scientist and software engineer, tasked with architecting a high-performance, analytics-driven goal tracking platform. This system must allow users to input goals, monitor ongoing progress, and access advanced visual analytics and reports for deep performance insights and continuous improvement.

#ROLE:
Adopt the role of a senior product architect specializing in goal tracking platforms, data analysis, user engagement, and dashboard visualization.

#RESPONSE GUIDELINES:
1. System Requirements:
   - List the essential features and core functionalities of the goal tracking system
   - Specify both user-facing and backend technical requirements
   - Focus on intuitive UX, high scalability, and actionable analytics

2. Data Model:
   - Define the database schema, including tables for users, goals, milestones, tasks, and real-time progress tracking
   - Detail relationships and critical attributes for each entity

3. Analytics & Visualization:
   - Identify core performance metrics and insights the system should deliver
   - Outline recommended chart types, dashboards, and visualization tools
   - Emphasize actionable insights, predictive analytics, and visual storytelling

4. Integration & Platform Compatibility:
   - Recommend integrations with popular productivity apps, calendars, and communication tools
   - Specify supported platforms (web, mobile, desktop, API)
   - Aim for a seamless, cross-device experience

5. Security & Privacy:
   - Detail best practices for data protection, authentication, and user privacy
   - Address encryption, secure data storage, and regulatory compliance

6. Implementation Roadmap:
   - Break development into key phases: MVP, core features, advanced analytics, user testing, and iteration
   - Prioritize rapid prototyping, robust QA, and agile feedback cycles

#TASK CRITERIA:
1. The refined prompt must retain all critical ideas and structure from the original.
2. The response must follow the provided structure—use the specified section headers only.
3. Do not add commentary, context, or explanations outside the defined structure.
4. Create a clear, complete, and actionable prompt that captures all requirements for the goal tracking system.

#INFORMATION ABOUT ME:
- System name: [SYSTEM NAME]
- Target users: [TARGET USERS]
- Primary goal: [PRIMARY GOAL]

#RESPONSE FORMAT:
Return the refined prompt in plain text only. Use the exact section labels and structure outlined above.

```

## ❓How to Use This Prompt:

● Replace [SYSTEM NAME], [TARGET USERS], and [PRIMARY GOAL] with your system’s name, intended user group, and main objective.

- Example: If your platform is "FocusSuite", your users are "remote teams and project managers", and your main goal is "maximizing accountability and cross-team goal achievement", fill in accordingly.
