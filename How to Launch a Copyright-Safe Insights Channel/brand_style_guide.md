# Brand Style Guide: Daily Insights Channel

## 1. Brand Overview

### Brand Essence
The Daily Insights Channel is a professional, authoritative, yet approachable source of niche-specific news and analysis. The brand delivers high-value, curated information that helps viewers stay ahead of trends and make informed decisions.

### Brand Values
- **Trustworthiness**: Delivering accurate, well-researched information
- **Efficiency**: Respecting viewers' time with concise, focused content
- **Insight**: Going beyond facts to provide meaningful analysis
- **Consistency**: Reliable daily updates that viewers can count on
- **Accessibility**: Making complex information easy to understand

### Brand Voice
- **Professional but not stuffy**
- **Confident but not arrogant**
- **Informative but not boring**
- **Concise but not rushed**
- **Authoritative but not condescending**

## 2. Visual Identity

### Logo
The logo should be simple, professional, and instantly recognizable. It should work well at small sizes (for profile pictures) and large sizes (for intro/outro animations).

#### Logo Variations
- **Primary Logo**: Full logo with icon and wordmark
- **Icon Only**: For profile pictures and small applications
- **Wordmark Only**: For text-based applications

#### Logo Clear Space
Always maintain a clear space around the logo equal to the height of the icon.

#### Logo Minimum Size
The logo should never be smaller than 30px in height to maintain legibility.

### Color Palette

#### Primary Colors
- **Deep Blue** (#1A365D): Represents trust, professionalism, and authority
- **Vibrant Orange** (#FF7F50): Represents energy, enthusiasm, and insight

#### Secondary Colors
- **Light Blue** (#4A90E2): For backgrounds and supporting elements
- **Light Gray** (#F5F5F5): For backgrounds and text blocks
- **Dark Gray** (#333333): For body text

#### Accent Colors
- **Success Green** (#27AE60): For positive trends or developments
- **Alert Red** (#E74C3C): For negative trends or urgent news

### Typography

#### Primary Font: Montserrat
- **Headings**: Montserrat Bold
- **Subheadings**: Montserrat SemiBold
- **Body Text**: Montserrat Regular

#### Secondary Font: Open Sans
- **Body Text Alternative**: Open Sans Regular
- **Captions**: Open Sans Light Italic

#### Font Sizes
- **Video Title**: 36px
- **Section Headers**: 28px
- **Body Text**: 18px
- **Captions/Notes**: 14px

### Imagery Style

#### Photography
- High-quality stock photos or custom photography
- Clean, well-lit images with good contrast
- Business/professional settings relevant to the niche
- Avoid overly staged or artificial-looking stock photos

#### Icons and Graphics
- Simple, flat design icons
- Consistent stroke weight
- Rounded corners for a friendly feel
- Monochromatic with accent colors used sparingly

## 3. Video Elements

### Thumbnails
- Consistent template with space for:
  - Bold headline text (3-5 words maximum)
  - Relevant image or graphic
  - Channel branding element
- High contrast for visibility at small sizes
- Text should be legible on mobile devices
- Use emotion-evoking imagery when possible

### Intro Animation
- Brief (5-7 seconds maximum)
- Include logo animation
- Professional sound effect or music bed
- Establish brand colors and visual style

### Lower Thirds
- Clean, minimal design
- Left-aligned text
- Two-tier design: Name/Title on top, Description below
- Semi-transparent background for better legibility
- Subtle animation for entrance/exit

### Title Cards
- Bold, centered text
- Subtle background animation or gradient
- Consistent with overall brand style
- 3-5 seconds duration

### End Screen
- Clear call-to-action elements
- Space for two recommended videos
- Subscribe button prominently displayed
- Social media handles
- Clean, uncluttered layout

## 4. Social Media

### Profile Pictures
- Use the icon-only version of the logo
- Maintain consistent branding across all platforms
- Ensure the icon is centered and has adequate padding

### Cover Images
- Use the primary brand colors
- Include the full logo
- Add a tagline or value proposition
- Keep text minimal and centered

### Post Templates
- Consistent layout for different types of posts
- Incorporate brand colors and typography
- Include logo or icon for brand recognition
- Use consistent hashtags relevant to your niche

## 5. Application Guidelines

### Do's
- Use the brand colors consistently
- Maintain adequate white space around elements
- Ensure text is legible against backgrounds
- Keep designs clean and uncluttered
- Use high-quality images and graphics

### Don'ts
- Don't distort or modify the logo
- Don't use colors outside the brand palette
- Don't use more than two fonts
- Don't overcrowd designs with too many elements
- Don't use low-quality or pixelated images

## 6. File Formats and Resources

### Logo Files
- AI/EPS vector files for print
- PNG with transparent background for digital
- JPG for social media
- SVG for web applications

### Font Files
- OTF/TTF files for Montserrat and Open Sans
- Web font kit for website implementation

### Color Swatches
- Adobe Swatch Exchange (.ase) file
- RGB values for digital applications
- CMYK values for print applications
- HEX codes for web applications
