## ⚡ Quick Start (5 Steps)

### 1. Download & Extract
- Download the ZIP file
- Extract to your Desktop
- Open the folder

### 2. Install
- Double-click `INSTALL.bat` (Windows) or `install.sh` (Mac/Linux)
- Wait 2-3 minutes
- Done!

### 3. Add API Key
- Get OpenAI API key from: https://platform.openai.com/api-keys
- Open `config.txt`
- Paste your key
- Save

### 4. Start System
- Double-click `START.bat` (Windows) or `start.sh` (Mac/Linux)
- Browser opens automatically
- See your dashboard!

### 5. Test Everything
- Follow TESTING_GUIDE.md
- Test all 12 features
- Verify everything works

**Total time: 30 minutes to 1 hour**

## 🆘 Common Issues & Solutions

### "Python not found"
**Solution**: Install Python from python.org, check "Add to PATH"

### "API Key Error"
**Solution**: Check config.txt, make sure key starts with "sk-"

### "System won't start"
**Solution**: Run INSTALL.bat first, then START.bat

### "Dashboard is blank"
**Solution**: Wait 30 seconds, refresh page (F5)

### "No proposals generating"
**Solution**: Check OpenAI API credits, verify internet connection
