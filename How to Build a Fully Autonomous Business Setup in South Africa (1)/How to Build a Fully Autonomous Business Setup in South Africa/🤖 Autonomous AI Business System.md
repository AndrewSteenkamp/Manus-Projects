## 🚀 Quick Start (For Complete Beginners)

### Step 1: Download Everything
1. Click the green "Code" button at the top of this page
2. Click "Download ZIP"
3. Save it to your Desktop
4. Right-click the ZIP file → "Extract All"

### Step 2: Install Python (The Language This Runs On)
1. Go to: https://www.python.org/downloads/
2. Click the big yellow "Download Python" button
3. Run the installer
4. **IMPORTANT**: Check the box that says "Add Python to PATH"
5. Click "Install Now"
6. Wait for it to finish
7. Click "Close"

### Step 3: Install the AI System
1. Open the folder you extracted (should be called "autonomous_business")
2. Look for a file called `INSTALL.bat` (on Windows) or `install.sh` (on Mac/Linux)
3. **Double-click it**
4. A black window will appear - this is normal!
5. Wait 2-3 minutes while it installs everything
6. When it says "Installation Complete!", close the window

### Step 4: Configure Your API Key
1. Go to: https://platform.openai.com/api-keys
2. Create an account (if you don't have one)
3. Click "Create new secret key"
4. Copy the key (it looks like: sk-proj-abc123...)
5. Open the file called `config.txt` in the autonomous_business folder
6. Paste your API key where it says `YOUR_API_KEY_HERE`
7. Save and close the file

### Step 5: Start the System
1. Look for a file called `START.bat` (Windows) or `start.sh` (Mac/Linux)
2. **Double-click it**
3. A window will open showing the system starting
4. After 10-20 seconds, your web browser will automatically open
5. You'll see the **AI Business Dashboard**

**That's it! You're now running an AI business!** 🎉

## 💳 Setting Up Payments (So You Can Get Paid!)

### Step 1: Create PayFast Account
1. Go to: https://www.payfast.co.za
2. Click "Sign Up"
3. Choose "Business Account"
4. Fill in your details
5. Upload FICA documents (ID, proof of address)
6. Wait 24-48 hours for approval

### Step 2: Get Your PayFast Credentials
1. Log into PayFast dashboard
2. Go to "Settings" → "Integration"
3. Copy your:
   - Merchant ID
   - Merchant Key
4. Create a Passphrase (make it strong!)

### Step 3: Add to Your System
1. Open `config.txt` in your autonomous_business folder
2. Add your PayFast details:
   ```
   PAYFAST_MERCHANT_ID=your_merchant_id_here
   PAYFAST_MERCHANT_KEY=your_merchant_key_here
   PAYFAST_PASSPHRASE=your_passphrase_here
   ```
3. Save the file
4. Restart the system

**Now when you create invoices, they'll have real payment links!**

## 🆘 Troubleshooting

### Problem: "System won't start"
**Solution**:
1. Make sure Python is installed
2. Check you ran `INSTALL.bat` first
3. Try restarting your computer

### Problem: "API Key Error"
**Solution**:
1. Check your OpenAI API key in `config.txt`
2. Make sure you copied it correctly (no extra spaces)
3. Verify your OpenAI account has credits

### Problem: "Dashboard is blank"
**Solution**:
1. Wait 30 seconds (it takes time to load)
2. Refresh the page (F5)
3. Check your internet connection

### Problem: "PayFast not working"
**Solution**:
1. Verify your PayFast account is approved
2. Check your credentials in `config.txt`
3. Make sure you're using the right Merchant ID
