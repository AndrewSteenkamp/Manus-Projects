# Launch Checklist
**Everything You Need Before Going Live**

Use this checklist to make sure your Alpapies store is ready to accept real customers and orders.

---

## Pre-Launch Checklist

### ✅ Website Basics

- [ ] **Website loads correctly**
  - Test: Open your public URL
  - Everything should load fast and look professional

- [ ] **All pages work**
  - [ ] Homepage
  - [ ] Products page
  - [ ] Individual product pages
  - [ ] Shopping cart
  - [ ] Checkout
  - [ ] Admin dashboard

- [ ] **Mobile-friendly**
  - Test: Open website on your phone
  - Should look good and work smoothly

### ✅ Products

- [ ] **Remove sample products**
  - Delete the 9 test products (leather cases, chargers, etc.)
  - Or keep them if you're actually selling those!

- [ ] **Add your real products**
  - At least 10-20 products to start
  - Each with:
    - [ ] Clear product name
    - [ ] Detailed description
    - [ ] High-quality photos
    - [ ] Correct pricing
    - [ ] Proper category
    - [ ] SKU/product code

- [ ] **Check all product pages**
  - Click on each product
  - Make sure everything displays correctly
  - Test "Add to Cart" button

### ✅ Pricing

- [ ] **Prices are profitable**
  - Calculate: Supplier cost + Shipping + Your profit
  - Make sure you're making money on each sale!

- [ ] **Discounts make sense**
  - Original price should be realistic
  - Discount percentage should be attractive (30-50%)

- [ ] **Shipping costs set**
  - Decide: Free shipping or charge customers?
  - If charging, how much?

### ✅ Payment Processing

- [ ] **PayFast account created**
  - Signed up at payfast.co.za
  - Account verified and approved
  - Bank details added

- [ ] **API keys obtained**
  - Merchant ID
  - Merchant Key
  - Passphrase

- [ ] **Payment integrated**
  - Gave keys to Manus AI
  - Payment system tested
  - Test transaction successful

- [ ] **Live mode activated**
  - Switched from Sandbox to Live
  - Real payments now work

### ✅ Supplier Setup

- [ ] **ZQ Dropshipping account**
  - Account created
  - Contact person assigned
  - Communication method established (email, WhatsApp, etc.)

- [ ] **Product sources confirmed**
  - Have 1688.com URLs for all products
  - Confirmed availability with ZQ
  - Know lead times (how long to ship)

- [ ] **Pricing confirmed**
  - Know exact costs for each product
  - Know shipping costs
  - No surprises when ordering

### ✅ Legal & Policies

- [ ] **Terms of Service**
  - Created or using template
  - Covers refunds, shipping, etc.
  - Link added to website footer

- [ ] **Privacy Policy**
  - Explains how you handle customer data
  - Link added to website footer

- [ ] **Refund Policy**
  - Clear rules: 30 days? 14 days?
  - Conditions: unopened? with receipt?
  - Displayed on website

- [ ] **Shipping Policy**
  - Delivery times stated
  - Shipping costs explained
  - International shipping rules

### ✅ Communication

- [ ] **Business email set up**
  - Professional email (not personal Gmail)
  - Example: orders@alpapies.com or hello@alpapies.com

- [ ] **Email templates ready**
  - Order confirmation
  - Shipping notification
  - Tracking number
  - Delivery confirmation

- [ ] **Customer support plan**
  - How will customers contact you?
  - Email? WhatsApp? Phone?
  - Response time goal (24 hours?)

### ✅ Domain & Branding

- [ ] **Custom domain connected**
  - elpapies.com (or alpapies.com)
  - DNS configured correctly
  - Website loads on your domain

- [ ] **Branding consistent**
  - Logo uploaded
  - Colors match your brand
  - Website name correct everywhere

- [ ] **Social media**
  - Facebook page created (optional)
  - Instagram account (optional)
  - Links added to website

### ✅ Testing

- [ ] **Complete test purchase**
  - Add product to cart
  - Go through checkout
  - Complete payment (small amount)
  - Verify order appears in admin
  - Test refund process

- [ ] **Test on different devices**
  - Desktop computer
  - Laptop
  - Tablet
  - Mobile phone (Android)
  - Mobile phone (iPhone)

- [ ] **Test with different browsers**
  - Chrome
  - Safari
  - Firefox
  - Edge

- [ ] **Ask someone else to test**
  - Friend or family member
  - Watch them use the site
  - Note any confusion or issues

### ✅ Admin Setup

- [ ] **Know how to access admin**
  - Bookmark admin URL
  - Password saved securely

- [ ] **Know how to add products**
  - Practiced adding a product
  - Know where everything is

- [ ] **Know how to process orders**
  - Understand the workflow
  - Have ZQ contact info ready

- [ ] **Set up order tracking**
  - Spreadsheet or system ready
  - Know how to record costs and profits

- [ ] **Final website check**
  - Everything still works?

- [ ] **Payment system check**

  - Test transaction works?

  - Share your new store

- [ ] **Monitor closely**
  - Check website every few hours

- [ ] **Be ready to fix issues**
  - Have Manus AI on standby

- [ ] **Celebrate first sale!**

  - Process it perfectly

## Week 1 Goals

### Days 1-7:

- [ ] **Process all orders within 24 hours**
  - Forward to ZQ same day
  - Send tracking numbers promptly

- [ ] **Respond to all inquiries**
  - Within 24 hours maximum
  - Be helpful and friendly

- [ ] **Track everything**
  - Record all orders
  - Calculate profits
  - Note any issues

- [ ] **Gather feedback**
  - Ask customers about their experience
  - Note what works and what doesn't

- [ ] **Make improvements**
  - Fix any issues found
  - Add more products if needed
  - Adjust prices if necessary

## Red Flags (Don't Launch If...)

### ❌ Stop and Fix These First:

- [ ] **Website doesn't load**
  - Fix before launching!

- [ ] **Payment doesn't work**
  - Critical! Must work perfectly

- [ ] **No products added**
  - Need at least 10-20 products

- [ ] **Can't contact ZQ**
  - Must have reliable supplier

- [ ] **Don't understand order process**
  - Practice with test orders first

- [ ] **No way for customers to contact you**
  - Add email or contact form

✅ Website works perfectly

**If you're not ready, that's okay!** Take your time. It's better to launch right than to launch fast.
