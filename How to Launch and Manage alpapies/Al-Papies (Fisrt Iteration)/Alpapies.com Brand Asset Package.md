# Alpapies.com Brand Asset Package

## Logo Files Included

### Primary Logo Variations
- **Horizontal Logo**: Shield + wordmark (primary usage)
- **Vertical Logo**: Stacked shield and text (square spaces)
- **Icon Only**: Shield symbol (social media, app icon)
- **Monochrome Versions**: Black, white, single color options

### File Formats Available
- PNG (transparent background) - for web and digital use
- SVG (vector format) - for scalable applications
- EPS (vector format) - for print applications
- JPG (solid background) - for specific use cases

## Color Specifications

### Primary Colors
- **Shield Blue**: #1E3A8A (RGB: 30, 58, 138)
- **Text Navy**: #1F2937 (RGB: 31, 41, 55)
- **White**: #FFFFFF (RGB: 255, 255, 255)

### Secondary Colors
- **Light Gray**: #F3F4F6 (RGB: 243, 244, 246)
- **Accent Blue**: #3B82F6 (RGB: 59, 130, 246)

## Typography

### Primary Font
- **Font Family**: Inter or similar modern sans-serif
- **Weights**: Regular (400), Medium (500), Bold (700)
- **Usage**: All brand applications, website, marketing materials

### Fallback Fonts
- System fonts: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif

## Logo Usage Guidelines

### Minimum Sizes
- **Horizontal Logo**: 120px width minimum
- **Vertical Logo**: 80px width minimum  
- **Icon Only**: 32px minimum for digital, 15mm for print

### Clear Space
- Maintain clear space equal to the height of the shield around all logo variations
- No other elements should appear within this protected area

### Proper Usage
✅ Use on white or light backgrounds
✅ Maintain original proportions
✅ Use approved color variations
✅ Ensure adequate contrast

### Avoid
❌ Stretching or distorting the logo
❌ Using on busy backgrounds without proper contrast
❌ Changing colors outside approved palette
❌ Adding effects, shadows, or outlines
