# How to Manage Orders
**A Complete Guide for Beginners**

This guide shows you how to handle customer orders from start to finish.

---

## Understanding the Order Flow

### What Happens When a Customer Orders:

1. **Customer places order** on your website
2. **You receive notification** (email when set up)
3. **You see order in admin dashboard**
4. **You forward order to ZQ Dropshipping**
5. **ZQ sources product from 1688.com**
6. **ZQ ships to customer**
7. **You provide tracking number to customer**
8. **Customer receives product**
9. **You mark order as completed**

## Order Statuses Explained

### 🟡 Pending
- Customer placed order
- Payment not yet confirmed
- **What to do**: Wait for payment confirmation

### 🔵 Processing
- Payment confirmed
- You're working on fulfilling it
- **What to do**: Forward to ZQ Dropshipping

### 🟢 Completed
- Product shipped and delivered
- Customer received their order
- **What to do**: Nothing, order is done!

### 🔴 Cancelled
- Order was cancelled
- By customer or by you
- **What to do**: Issue refund if payment was made

### Example Order:

### Step 1: Verify the Order
1. Check all information is correct
2. Verify shipping address is complete
3. Confirm payment received (when payment is set up)

### Step 2: Forward to ZQ Dropshipping
**Email Template to ZQ:**
```

John Smith

South Africa

Please confirm receipt and provide:
- Total cost
- Estimated shipping time
- Tracking number when shipped

Andrew
Alpapies
```

### Step 3: Update Order Status
1. In admin dashboard, click on the order
2. Change status to "Processing"
3. Add note: "Forwarded to ZQ Dropshipping on [date]"
4. Save changes

### Step 4: Wait for ZQ Confirmation
- ZQ will reply with:
  - Total cost confirmation
  - Estimated delivery time
  - Any issues with products

### Step 5: Pay ZQ Dropshipping
- They'll send invoice
- Pay via their preferred method
- Keep receipt for your records

### Step 6: Get Tracking Number
- ZQ ships the order
- They provide tracking number
- Usually within 2-3 days

### Step 7: Send Tracking to Customer
**Email Template to Customer:**
```

Alpapies
ahsteenkamp@gmail.com
```

### Step 8: Update Order with Tracking
1. Go back to order in admin
2. Add tracking number
3. Update status if needed
4. Save changes

### Step 9: Monitor Delivery
- Check tracking periodically
- If there are delays, contact ZQ
- Be proactive if customer asks about their order

### Step 10: Mark as Completed
- Once customer receives product
- Change status to "Completed"
- Order is done!

## Handling Common Situations

### Customer Asks "Where is my order?"
1. Check order status in admin
2. Look up tracking number
3. Check tracking website
4. Reply with update:
   ```
   Hi [Name],
   
   Your order is currently [status]. 
   Tracking shows it's [location/status].
   Expected delivery: [date]
   
   Tracking: [URL]
   ```

### Product is Out of Stock at 1688.com
1. Contact ZQ immediately
2. Ask for alternatives
3. If no alternative:
   - Contact customer
   - Offer refund or different product
   - Apologize for inconvenience

### Customer Wants to Cancel
**Before shipping:**
1. Contact ZQ to stop shipment
2. Issue full refund
3. Update order status to "Cancelled"

**After shipping:**
1. Explain it's already shipped
2. Offer return once received
3. Provide return instructions

### Wrong Address
1. Contact ZQ immediately
2. If not shipped yet, update address
3. If already shipped, contact carrier
4. May need to pay address change fee

### Customer Not Happy with Product
1. Apologize for the issue
2. Ask for photos of the problem
3. Options:
   - Partial refund
   - Full refund + return
   - Replacement
4. Learn from it - maybe don't sell that product again

## Monthly Order Review

### At End of Each Month:
1. **Count orders**: How many did you get?
2. **Calculate revenue**: Total customer payments
3. **Calculate costs**: Total paid to ZQ
4. **Calculate profit**: Revenue - Costs
5. **Identify best sellers**: Which products sold most?
6. **Check problems**: Any recurring issues?
7. **Plan ahead**: Order more of best sellers
